# تطبيق الآلة الحاسبة الذكي (Smart Calculator App)

تطبيق آلة حاسبة متكامل واحترافي مصمم بنظام **Material Design 3** لأجهزة أندرويد، مكتوب بلغة **Kotlin** مع إطار العمل الحديث **Jetpack Compose**.

---

## 🌟 المميزات الرئيسية

### 1. الوظائف الحسابية المتقدمة
- **العمليات الأساسية:** الجمع (`+`)، الطرح (`−`)، الضرب (`×`)، القسمة (`÷`).
- **النسبة المئوية (`%`):** حساب النسب المئوية المباشرة والمتسلسلة.
- **تغيير الإشارة (`±`):** التبديل السلس بين القيم الموجبة والسالبة.
- **الأسس والجذور:** حساب الأس (`^`) والجذر التربيعي (`√`) بدقة عالية.
- **الأقواس وترتيب العمليات (PEMDAS/BODMAS):** دعم الأقواس المفتوحة والمغلقة مع أولوية صحيحة 100%.
- **دقة حسابية فائقة:** استخدام محرك حسابي يعتمد على `BigDecimal` لمنع أخطاء الفاصلة العائمة (مثل `0.1 + 0.2 = 0.3`).
- **المعاينة الفورية (Real-time Preview):** عرض نتيجة العملية الحسابية مباشرة أثناء الكتابة وقبل الضغط على زر `=`.
- **معالجة الحالات الحدية والأخطاء:** منع القسمة على صفر، التعامل مع الأعداد الضخمة، والتحذير من العمليات غير الرياضية.
- **الحذف السريع والمرحلي:** زر لحذف آخر خانة (`⌫`) وزر لمسح العملية كاملة (`AC` / `C`).
- **النسخ واللصق:** إمكانية نسخ المعادلة أو النتيجة ولصق الأرقام بنقرة واحدة.

### 2. السجل الحسابي الذكي (Calculation History)
- حفظ تلقائي للعمليات السابقة مع وقت التنفيذ الدقيق.
- تخزين دائم ومحلي على الجهاز عبر قاعدة بيانات **Room Database** (SQLite).
- إمكانية إعادة استخدام المعادلة أو النتيجة في أي وقت بمجرد النقر عليها.
- خيار لحذف عنصر محدد أو مسح السجل كاملاً مع رسالة تأكيد.

### 3. التخصيص والمظهر
- **الأوضاع اللونية:** الوضع الفاتح (Light Mode)، الوضع الداكن (Dark Mode)، والوضع التلقائي (System Default).
- **6 ألوان متناسقة للواجهة:**
  - Teal & Slate (سماوي عصري)
  - Royal Indigo (نيلي ملكي)
  - Emerald Green (أخضر زمردي)
  - Sunset Amber (عنبري دافئ)
  - Vibrant Violet (بنفسجي مشرق)
  - AMOLED Pure Dark (أسود نقي لشاشات الأوليد)
- تطبيق المظهر فورياً دون الحاجة لإعادة تشغيل التطبيق.
- حفظ التفضيلات محلياً عبر **DataStore Preferences**.

### 4. تجربة الاستخدام والأداء
- استجابة لمسية فائقة السرعة مع تأثير انضغاط نابض سلس (Spring Animation).
- دعم الاهتزاز الخفيف (Haptic Feedback) وصوت النقر (Click Sound) مع إمكانية التفعيل أو التعطيل من الإعدادات.
- دعم التنقل وإدخال الأرقام والعمليات عبر لوحات المفاتيح الخارجية والافتراضية.
- يعمل بدون إنترنت (Offline 100%) وبدون أي إعلانات أو تسجيل دخول.

## 📱 التوافق والمتطلبات التقنية
- **الحد الأدنى للنظام (minSdk):** Android 7.0 (API 24) فما فوق (متوافق مع أكثر من 99% من أجهزة أندرويد).
- **الإصدار المستهدف (targetSdk):** Android 14+ (API 36).
- **الواجهة:** Jetpack Compose & Material 3.
- **قاعدة البيانات المحلية:** Android Jetpack Room.
- **حفظ الإعدادات:** Jetpack DataStore Preferences.

## 🚀 التجميع وإنتاج ملف الـ APK

### الطريقة الأولى: التجميع السحابي التلقائي عبر GitHub Actions (بدون تثبيت Android Studio)
تم إعداد ملف مسار عمل تلقائي جاهز في `.github/workflows/build.yml`:
1. ارفع المشروع إلى حسابك على **GitHub**.
2. توجّه إلى تبويب **Actions** في صفحة المستودع.
3. ستجد مسار العمل باسم **Build Android APK** يعمل تلقائياً عند الدفع (`Push`)، أو يمكنك تشغيله يدوياً عبر زر **Run workflow**.
4. بعد اكتمال البناء بنجاح (ظهور علامة الصح الخضراء ✅):
   - اضغط على اسم البناء (Build Run).
   - انزل لأسفل الصفحة إلى قسم **Artifacts**.
   - اضغط على **Calculator-Debug-APK** لتحميل ملف الـ `apk` الجاهز للتثبيت على هاتفك مباشرة.

### الطريقة الثانية: التجميع محلياً عبر سطر الأوامر (Gradle)
```bash
# تجميع نسخة الـ APK بصيغة Debug:
gradle :app:assembleDebug

# مسار ملف الـ APK الناتج:
# app/build/outputs/apk/debug/app-debug.apk
```
